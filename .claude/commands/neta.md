# ネタ収集・トレンド分析

退職系・AI系のトレンドを収集し、ネタストックに追加します。

## 使い方

```
/neta                    # トレンド自動収集
/neta 退職               # 退職系のネタを検索
/neta AI 画像生成        # AI系の特定トピックを検索
```

## 実行内容

1. **トレンド検索**
   - WebSearchで最新トレンドを取得
   - 退職系: 退職代行、転職、働き方改革など
   - AI系: 新サービス、話題のツール、使い方Tips

2. **ネタ整理**
   - タイトル、概要、ソースURLを抽出
   - ジャンル分類（退職系/AI系）
   - バズりやすさの評価

3. **ストック保存**
   - `knowledge/neta/` にJSON形式で保存
   - 重複チェック

## ネタファイル形式

```json
{
  "id": "neta_20241229_001",
  "title": "ネタタイトル",
  "summary": "概要",
  "genre": "AI系",
  "source": "https://...",
  "buzzPotential": "high",
  "status": "unused",
  "createdAt": "2024-12-29T12:00:00Z"
}
```

## 引数

$ARGUMENTS - 検索キーワード（省略時は自動でトレンド収集）
