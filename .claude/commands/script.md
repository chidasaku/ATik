# 台本生成

ネタから動画用の台本を生成します。

## 使い方

```
/script                  # ネタ一覧から選択して台本作成
/script VS形式           # VS形式のテンプレートで作成
/script ランキング       # ランキング形式で作成
```

## テンプレート

### VS形式
```
【フック】〇〇 vs △△、どっちが正解？

【本題】
〇〇派の意見：...
△△派の意見：...

【結論】実は...

【CTA】どっち派？コメントで教えて！
```

### ランキング形式
```
【フック】〇〇 TOP3！

【3位】...
【2位】...
【1位】...

【CTA】他にもあったらコメントで！
```

### あるある形式
```
【フック】〇〇あるある

【あるある1】...
【あるある2】...
【あるある3】...

【CTA】共感したらいいね！
```

## 実行内容

1. **ネタ選択**（引数なしの場合）
   - `knowledge/neta/` から未使用ネタを表示
   - ユーザーが選択

2. **テンプレート適用**
   - ジャンル設定を読み込み
   - ペルソナ・トーンを適用

3. **台本生成**
   - AI生成で台本作成
   - `knowledge/scripts/` に保存

## 引数

$ARGUMENTS - テンプレート指定（VS形式、ランキング、あるある）
